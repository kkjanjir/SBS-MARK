## 2024-07-28 - [Performance] Extracted Pure Functions and Memoized Components
**Learning:** Pure functions declared inside React components are re-created on every render, adding garbage collection overhead. Extracting them outside the component scope is a safe and effective micro-optimization. Further, passing complex inline objects (like `student_data || {}`) to heavily rendered components (like `React.memo(MarksheetTemplate)`) bypasses shallow equality checks. Memoizing the parent mapping operation (`bulkPrintContent`) avoids rendering thrash effectively.
**Action:** Always extract functions that don't depend on component state or props to the top level. Wrap complex mapping blocks in `useMemo` when they produce large JSX elements that shouldn't re-render unless source data changes.
