## 2024-05-18 - Prevent unnecessary re-renders of MarksheetTemplate
**Learning:** `MarksheetTemplate` component is rendered inside a large map loop for `classFilteredStudents` without any memoization. Since `classFilteredStudents.map` causes React to re-render all elements if parent state changes, it will cause a significant performance bottleneck by forcing all children to unnecessarily re-render. Additionally, it receives dynamically instantiated objects as fallback values for props like `student={s.student_data || {}}` and `coScholastic={s.extra_data?.coScholastic || {sports:'A',art:'A',music:'A',discipline:'A'}}`, which defeats React.memo's default shallow comparison.
**Action:** Extract the static fallback objects outside the component, and wrap `MarksheetTemplate` with `React.memo` using a custom `arePropsEqual` comparator that properly handles the equality of `subjectsList` array and shallow equality for `student`, `marks`, `extra`, and `coScholastic`. Also ensure `import React from 'react'` or `React.memo` is available.
