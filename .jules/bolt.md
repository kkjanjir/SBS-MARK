## 2024-07-19 - [Bulk Printing Re-render Bottleneck]
**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. The bulk print container renders a `MarksheetTemplate` for every student. This causes massive input lag when interacting with unrelated state (like forms) because each student template re-renders. When strictly resolving inline props for `React.memo` is too complex, wrapping the parent map operation inside a `useMemo` block serves as an effective optimization.
**Action:** When working on heavily rendered hidden components like `#print-bulk-container`, use `useMemo` at the parent level to prevent O(N) re-renders, and ensure the dependency array correctly captures the required state to prevent stale UI.
