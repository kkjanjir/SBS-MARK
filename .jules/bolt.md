## 2024-07-30 - Memoization of Hidden Print Containers
**Learning:** Elements hidden via CSS (e.g. `display: none` in `.print-area`) still execute full React render cycles. If they contain complex iteration mapping heavy components (like `MarksheetTemplate`), it creates an O(N) re-render penalty on unrelated state changes, leading to massive input lag. Additionally, inline objects used as fallbacks (`s.student_data || {}`) and purely functional array generations defeat shallow equality checks in `React.memo`.
**Action:** Heavily optimize mapping operations inside print containers by wrapping child components in `React.memo()`. Provide referentially stable props by using static definitions outside the component scope (`const defaultStudent = {}`), and pull heavy caching/helper functions outside of the React lifecycle to prevent constant recreation and cache invalidation.
