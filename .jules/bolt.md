## 2025-02-17 - Hidden Print Containers Cause Render Lag
**Learning:** In this application, components hidden via CSS (`display: none`, like the `#print-bulk-container`) still undergo full React render cycles whenever their parent component updates. Because the bulk print container maps over the entire class roster and heavily utilizes `MarksheetTemplate` with inline prop objects and derived calculations, it causes severe input lag application-wide during any unrelated state change (e.g. typing in an input).
**Action:** Heavily memoize elements within hidden print containers. Ensure derived data (`classFilteredStudents`), mapping functions (`getCalculations`, `getClassSubjects`, `getClassRank`), and the entire mapped output (`bulkPrintContent`) are wrapped in `useMemo`/`useCallback` at the top level to prevent O(N) re-renders. Pure utility functions (`getDynamicSubjects`, `getGrade`) should be extracted entirely outside the component.
