## 2025-02-18 - Heavy computations in hidden print containers
**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. Heavy computations or loops inside them (e.g. iterating over `classFilteredStudents` to generate multiple complex `MarksheetTemplate`s in `#print-bulk-container`) must be strongly memoized using `useMemo` assigned to variables at the top level to prevent O(N) re-renders and severe input lag on unrelated state changes.
**Action:** Always inspect hidden elements and thoroughly memoize map functions within large or hidden loops. Make sure to obey the Rules of Hooks by keeping `useMemo` at the top level of the component scope, above early returns (like `!isUnlocked`), and NEVER inline within JSX expressions. Also, extract non-state dependent helper functions entirely outside the main component scope to prevent unnecessary recreation.
