## 2023-10-27 - [React Render Optimization in Print View]
**Learning:** In a monolithic Next.js/React application where elements are hidden via CSS (like a bulk print container with `display: none`) and render large lists, they can still execute full React render cycles. If functions generating derived data (`getClassSubjects`, `getCalculations`) are not memoized, they trigger O(N) expensive recalculations on every minor state change (e.g., typing in an input field), causing severe application-wide lag.
**Action:** Extract purely functional, non-state dependent helpers entirely out of the component scope. Heavily utilize `useCallback` for functions that depend on component state, and apply `useMemo` specifically to large arrays of JSX elements inside hidden print containers to avoid invalidating React's virtual DOM diffing algorithm across the entire array.
