## 2025-02-28 - Bulk List Rendering Inside Hidden Elements Creates Severe Lag
**Learning:** In this application, elements hidden via CSS (like the print container `#print-bulk-container` which uses `@media screen { display: none }` logically) still execute full React render cycles. Because `MarksheetTemplate` calculates grades and extracts subjects per render, a simple search input typing caused O(N) re-renders for every keystroke. Even wrapping `MarksheetTemplate` in `React.memo` isn't fully effective alone if it receives inline default objects as props (e.g., `student={data || {}}`).
**Action:** When facing severe input lag in large components, look for hidden lists. Wrap the *entire mapping operation* in a `useMemo` block rather than just memoizing the child component. This completely shields the complex map loop and child components from unrelated parent state changes.
