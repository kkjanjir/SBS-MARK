## 2024-05-17 - [Optimizing Heavy Render Cycles with React.memo]
**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. The `MarksheetTemplate` component was heavily used in mapping operations (inside the bulk print container) and was re-rendering on unrelated state changes, causing significant lag. Furthermore, using inline fallbacks (e.g., `student={s.student_data || {}}`) bypasses shallow comparison.
**Action:** Extract default fallback objects (like `defaultStudent`, `defaultExtra`, `defaultCoScholastic`) outside the component scope to preserve referential equality, and wrap the complex rendering component (`MarksheetTemplate`) with `React.memo` to skip re-renders for identical props.
