## 2024-05-24 - [Memoization Anti-patterns in React]
**Learning:** Using inline objects inside component mapping functions (like `coScholastic={s.extra_data?.coScholastic || {sports:'A'...}}`) and pure functions (like `.filter()` or returning spread arrays `[...]`) break referential equality and invalidate `React.memo` shallow checks. Furthermore, large unmemoized `map` blocks within hidden CSS containers still execute on unrelated state changes (like typing in a text field) leading to significant main-thread lag.
**Action:** Extract pure helper functions and static default objects to the module level. Wrap heavy DOM mapping blocks inside `useMemo`, and use primitive caching (e.g., `Map`) for derived arrays returned by pure functions that are passed to memoized children.
