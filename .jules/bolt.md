
## 2024-05-30 - Extracting Pure Functions and Managing Referential Equality for React.memo
**Learning:** When using `React.memo` to optimize heavy components (like `MarksheetTemplate` which is mapped multiple times in the bulk print view), it is crucial to ensure props maintain referential equality. Inline functions, or helper functions defined within the main component without `useCallback` (e.g. `getGrade`, `getDynamicSubjects`), are recreated every render. Even worse, if these functions return new arrays (e.g., using spread syntax in `getDynamicSubjects`) or if inline default objects (`student={s.student_data || {}}`) are passed as props, `React.memo`'s shallow comparison will always fail, causing unnecessary re-renders of the heavy component.
**Action:** Extract pure, non-state dependent functions outside the component scope entirely. If they must return derived arrays/objects, use a caching mechanism (like a `Map` cache) to preserve referential equality. For inline default props, define static constant objects at the top level (`const defaultStudent = {}`) instead of using inline literals in JSX. Finally, wrap heavy parent mapping operations in `useMemo` as an additional layer of defense.
