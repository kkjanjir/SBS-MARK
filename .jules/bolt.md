## 2025-02-18 - [Optimization] React.memo on MarksheetTemplate
**Learning:** The application heavily renders `MarksheetTemplate` within an array loop (e.g. bulk print container). Since the component tree inside `MarksheetTemplate` is massive and identical between re-renders, not wrapping it in `React.memo` with a custom props equality check results in severe O(N) re-render lag when minor state updates occur. Standard `React.memo` shallow comparison is broken by array literals/dynamically generated props (e.g. `subjectsList={getClassSubjects(...)}`).
**Action:** When mapping over items and rendering heavy components, always wrap them in `React.memo`. If prop objects/arrays are generated inline, implement a custom `arePropsEqual` to perform deterministic deep comparison, maintaining stable render performance.
