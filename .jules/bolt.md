## 2023-08-28 - Component Re-rendering in Hidden Print Containers
**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. The bulk print container dynamically maps over potentially hundreds of heavily populated `MarksheetTemplate` components, leading to O(N) recalculations and application-wide input lag on every irrelevant state change. Inline arrays (like `.map` or `.filter`) and pure utility functions that are placed inline within components invalidate cache equality arrays.
**Action:** Always extract pure helper functions entirely out of the component scope to preserve referential equality. Deeply nested helper functions (like `getClassSubjects`) that depend on component state must be heavily memoized (using `useCallback`) alongside their array properties. Complex iterations over deeply nested structures must wrap both the array resolution and output assignment in strict `useMemo` hooks mapped at the component root level rather than directly inside inline map logic inside the render function.
