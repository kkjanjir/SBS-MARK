## 2024-05-24 - [Avoid O(N) Re-renders in Hidden Complex Components]
**Learning:** Complex hidden components (like `#print-bulk-container`) that map over large arrays and render heavy sub-components can cause severe input lag if not memoized, because they re-render on every state change (e.g., typing in an input field). Also, when memoizing with `useMemo`, we must ensure the hook is placed *before* any early returns (like `if (!isUnlocked)`) to obey React Hook Rules. In cases where inner helper functions are volatile, using `// eslint-disable-next-line react-hooks/exhaustive-deps` may be necessary.
**Action:** Always wrap heavy mapped components in `useMemo`, placing the hook at the top level of the component before early returns. Use the exhaustive-deps disable comment thoughtfully when volatile inline functions are involved.
