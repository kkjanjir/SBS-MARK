## 2026-05-25 - Hidden Component React Render Cycle Optimization\n**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. Consequently, computationally heavy components or mappings within these containers must be strongly memoized to prevent application-wide input lag on unrelated state changes.\n**Action:** Use `useMemo` and `useCallback` heavily for logic and arrays related to hidden print containers. Ensure pure functions are hoisted completely out of the React component body to prevent unnecessary closures and to keep dependency arrays clean.
