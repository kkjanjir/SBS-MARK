## 2023-10-25 - Extracted pure functions and memoized elements to avoid React O(N) re-renders
**Learning:** In a heavily data-driven React application, particularly one using large hidden components like `#print-bulk-container`, recalculating child functions inside components on every state change causes significant O(N) re-renders, introducing lag even on completely unrelated state updates. Pure helper functions shouldn't reside inside components unless they need state.
**Action:** Always extract pure helper functions to the outer module scope. For state-dependent component methods (e.g. `getClassSubjects`, `getCalculations`, `getClassRank`), wrap them in `useCallback`. Crucially, memoize computationally heavy UI elements mapped from arrays using `useMemo` at the top level of the component scope to avoid continuous recalculations. Wrap high-usage presentational components (like `MarksheetTemplate`) in `React.memo()`.
