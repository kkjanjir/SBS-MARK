## 2024-03-24 - Extracted helpers and heavily memoized components to prevent bulk print re-renders
**Learning:** Hidden print containers (`display: none`) still execute full React render cycles. The application was experiencing severe input lag on every keystroke because the bulk print container (rendering all students in the class) was re-rendering completely every time the `marks` or `activeSubjectIdx` states changed. Additionally, defining helpers (`parseCsvLine`, `getDynamicSubjects`, `getGrade`) inside the main component component was causing unnecessary recreation and cache invalidation.
**Action:** Move purely functional helper functions outside the main component. Wrap `MarksheetTemplate` with `React.memo()`. Heavy calculations for hidden bulk print container must be strongly memoized using `useMemo` at the top level to prevent O(N) re-renders. When using `useMemo`, remember to also wrap the dependencies (like `getCalculations` and `getClassSubjects`) in `useCallback` to prevent stale closures. Ensure all React hooks are placed above early returns.
