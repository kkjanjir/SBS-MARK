## 2025-02-23 - Prevented Massive Re-Renders in Bulk Printing
**Learning:** In React applications, when rendering large lists of complex components, passing inline fallback objects (e.g., `s.student_data || {}`) defeats `React.memo` shallow comparison by creating new references. Additionally, dynamically derived array props (like `subjectsList`) require custom comparator functions (`arePropsEqual`) for array-equality, while the rest of the props can use strict referential equality.
**Action:** Extract fallback objects to static constants (e.g., `defaultStudent = {}`) to ensure referential stability. When memoizing components with dynamically derived array props, provide a strict custom comparator that iterates the array but relies on referential equality for all other props.
