## 2024-07-28 - Optimized Hidden Print Bulk Rendering
**Learning:** In this application, elements hidden via CSS (like print containers with `display: none`) still execute full React render cycles. The `MarksheetTemplate` component is heavily used in a bulk rendering map. When inline objects (e.g., `student={s.student_data || {}}`) are passed as props, they create new object references on every render, invalidating the shallow equality check of `React.memo` and causing O(N) re-renders, which leads to severe application lag on unrelated state changes (like typing a search query).
**Action:** Extract pure helper functions (like `getDynamicSubjects`, `getGrade`) outside the component. Wrap parent helper functions (like `getCalculations`, `getClassSubjects`) in `useCallback`. Define static default objects (`defaultStudent = {}`) outside the component instead of inline fallbacks. Memoize the large bulk render block using `useMemo` assigning the result to a variable, and wrap the heavy display component in `React.memo` to ensure its rendering is skipped unless explicit data changes.
