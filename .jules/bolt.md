## 2024-05-15 - [Initial performance review]
**Learning:** `app/page.tsx` is a monolithic React component with complex state and many inline utility functions like `getCalculations` and `getClassSubjects`. There is no `useMemo` or `useCallback` used to memoize values. In particular, `#print-bulk-container` re-renders every time the component updates because `classFilteredStudents` maps over `dbStudents.filter()` inside the component body, and `getCalculations` is called for every student in the list, recreating objects every render.
**Action:** Add `useMemo` for heavy computations like `classFilteredStudents` and `#print-bulk-container` contents to prevent input lag during normal UI interactions. Wrap inline functions like `getDynamicSubjects`, `getClassSubjects`, `getCalculations`, and `getClassRank` in `useCallback`.
