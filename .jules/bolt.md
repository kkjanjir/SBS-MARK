## 2024-05-24 - React.memo on Heavily Rendered Component
**Learning:** In this application, elements hidden via CSS (like print containers with display: none) still execute full React render cycles. The `MarksheetTemplate` component is heavily used in mapping operations inside the bulk print container. Without `React.memo()` and extracting purely functional helpers like `getDynamicSubjects` and `getGrade` outside the main component scope, it triggers heavy O(N) re-renders, causing severe input lag on unrelated state changes.
**Action:** Extract pure helper functions outside the component scope and wrap heavily rendered components in `React.memo()` to prevent unnecessary heavy DOM recalculations during state changes. Ensure inline objects/arrays passed as props are cached (using default constants) to maintain referential equality.
