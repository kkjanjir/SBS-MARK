## 2026-08-27 - Array Mapping Performance Trap\n**Learning:** When using React.memo on heavily mapped components (like BulkMarksheetRenderer), inline objects (e.g. `student={data || {}}`) or dynamic array calculations inside the map function instantly break referential equality, defeating the memoization entirely.\n**Action:** Always hoist default objects (e.g., `DEFAULT_MARKS`) outside the component scope as global constants, and use `useMemo` or dedicated renderer components to isolate and stabilize non-primitive props before passing them down.
