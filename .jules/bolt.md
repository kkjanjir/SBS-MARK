## 2024-05-24 - Hidden Elements Are Still Rendered
**Learning:** In a single-page React app, elements that are hidden using CSS `display: none` (such as a `#print-bulk-container` mapped over large arrays of data meant only for the print view) are *still* parsed and rendered entirely on every React render cycle. When `classFilteredStudents` maps over an entire class roster and repeatedly calls `MarksheetTemplate`, this can introduce severe main thread lag (O(N) operations) whenever non-related state (like search input or prompts) updates.
**Action:** When mapping heavy data or calling multiple functional components inside visually hidden areas, always use `useMemo` specifically on the list of JSX elements returned by the map function, assign it to a memoized variable, and inject the result. Combined with extracting non-state-dependent helper functions outside of the component, this completely mitigates the invisible performance trap.
