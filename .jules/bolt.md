## 2024-05-18 - Hidden Print Containers Cause O(N) Re-renders
**Learning:** In this application, elements like `#print-bulk-container` are hidden via CSS `display: none` but still execute full React render cycles. Mapping a large number of components (like MarksheetTemplates) inside these hidden containers causes severe application-wide input lag on every unrelated state change (e.g. typing a search query) because the virtual DOM for all those elements is recalculated.
**Action:** When working with hidden print or bulk containers, you must strictly wrap the mapped content in `useMemo` at the top level of the component and ensure all dependency props (like helper functions) are properly wrapped in `useCallback`. Furthermore, heavily used child components (`MarksheetTemplate`) must be wrapped in `React.memo` with pure function and fallback dependencies extracted outside the component.
