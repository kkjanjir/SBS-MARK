## 2026-05-06 - Memoizing elements that are always rendered but hidden
**Learning:** In a monolithic React application, when you render list items that are hidden by CSS (e.g. `display: none` via media queries like `@media print`), the component still renders them on every state change unless explicitly memoized. This can cause O(N) rendering operations that lead to severe input lag. Helper functions that generate or filter array lists used to populate hidden content must be wrapped in `useCallback`, the resulting element collections wrapped in `useMemo`, and leaf components wrapped in `memo`.
**Action:** When evaluating input lag in monolithic apps with hidden print containers or similar hidden heavy DOM nodes, ensure all map operations producing these nodes are wrapped in `useMemo` and that any helper functions invoked within the loop use `useCallback` with appropriate dependencies.
