## 2024-09-10 - [Heavy Render Maps in Hidden Print Containers]
**Learning:** In a monolithic app architecture where a large mapping of heavy components (`MarksheetTemplate`) is placed inside a hidden CSS container (`#print-bulk-container`, which uses `display: none;` on screen but `display: block;` on print), React still executes full render cycles for these hidden components whenever unrelated state changes (like typing in a search bar). Also, using `defaultProps = {}` inside component renders breaks `React.memo`'s shallow equality check, forcing re-renders despite memoization.
**Action:** Extract static default props entirely out of the component scope to preserve referential stability. Furthermore, if individual components are difficult to deeply memoize perfectly due to complex props, wrapping the *entire mapping operation* inside a single `useMemo` block ensures that the massive subtree is completely skipped during unrelated state updates, significantly reducing application-wide input lag.
